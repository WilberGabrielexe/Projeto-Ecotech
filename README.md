# 🌱 EcoTech TGA — Gestão Consciente de Lixo Eletrônico

Aplicação Web Progressiva (**PWA**) desenvolvida como projeto de extensão universitária do curso de **Análise e Desenvolvimento de Sistemas**, com foco na educação ambiental e no mapeamento de pontos de coleta de resíduos eletroeletrônicos em **Tangará da Serra - MT**.

## 🚀 Funcionalidades Principais

1. **Guia de Triagem e Informativos:** Orientação visual sobre o que pode ou não ser descartado, impacto ambiental de metais pesados e links para portais oficiais (ONU Global E-waste Monitor, ABREE, Green Eletron e gestão municipal).
2. **Pontos de Coleta em Tangará da Serra:** Integração direta com rotas no Google Maps destacando a **COOPERTAN** (ponto principal), os **Ecopontos do SAMAE** e instituições de ensino parceiras (**IFMT / UNEMAT**).
3. **Quiz Educativo Interativo:** Questionário rápido de 5 perguntas com feedback explicativo imediato para fixação do conteúdo junto a estudantes e moradores.
4. **Registro Comunitário de Descartes:** Formulário integrado via API ao **Google Sheets** para contabilizar bairros participantes, categorias de materiais e volume de peças destinadas corretamente.
5. **Segurança, LGPD e Transparência:** Aba dedicada às boas práticas de sanitização de dados pessoais antes do descarte (remoção de chips, contas e restauração de fábrica) e segurança no manuseio de baterias.
6. **Painel Administrativo e Cartaz A4:** Dashboard com indicadores em tempo real, gráficos por bairro/categoria, exportação em PDF e gerador de cartaz com QR Code para divulgação em escolas e espaços públicos.

## 🛠️ Stack Tecnológica

- **Frontend:** HTML5, CSS3 (Dark Mode responsivo) e JavaScript Vanilla (ES6+)
- **PWA & Offline:** Web App Manifest (`manifest.json`) e Service Worker (`sw.js`)
- **Backend & Persistência:** Google Sheets + Google Apps Script (`doPost` / `doGet`)
- **Hospedagem:** GitHub Pages
